# AI Daily Dashboard · 日报 / 周报 / 月报

基于 [AIHOT](https://aihot.virxact.com) 公开 API 的 AI 资讯仪表盘。**单文件 HTML，无框架、无构建、无外部依赖**，数据在浏览器端实时拉取。

**在线访问**：https://wwengu.github.io/ai-daily-dashboard/

---

## 功能

### 三视图切换（顶部三个 tab，切换后整个页面内容变化）

| 视图 | 内容 | 数据来源 |
|---|---|---|
| **日报** | 近期热点 + 五个版块（模型发布/产品发布/行业动态/论文研究/技巧与观点）卡片墙 | `hot-topics` + `items` 24h 精选 |
| **周报** | 本周 7 天官方导语时间线 + 本周精选 | 日报归档 `leadTitle` + `items` 7d 精选 |
| **月报** | 统计条 + 编号看点 + 30 天脉络（按 ISO 周分组） | 日报归档 `leadTitle` |

### 交互与体验

- **卡片 / 时间线点击弹窗**：完整摘要 + 「AIHOT 详情」+「查看原文」两个出口；时间线点击会拉取当日日报的版块概览，不直接跳走
- **空摘要自动补全**：无 `summary` 的条目自动拉取 AIHOT 事件综述（`story` 的 `digest` + `latest`）
- **阅读管理**：收藏（★）、已读标记、未读筛选、搜索（标题/摘要/来源）
- **深色模式**：右上角切换，localStorage 记忆
- **实时天气**：当前温度、体感、湿度、风速，12 个城市切换（默认广州）

## 数据来源

| 用途 | 接口 | 说明 |
|---|---|---|
| 日报 | `/api/v1/dailies/latest` | 含日期、窗口、五版块 |
| 日报归档 | `/api/v1/dailies?limit=N` | **周报/月报的核心来源**，每期含官方头条导语 `leadTitle` |
| 单日详情 | `/api/v1/dailies/{date}` | 时间线弹窗内拉取当日完整版块 |
| 热点 | `/api/v1/hot-topics` | 热度排名 + 参与信源数 |
| 分类精选 | `/api/v1/items?mode=selected&category=<slug>&window=24h` | 五个固定版块 |
| 天气 | Open-Meteo `current` 接口 | 开源，无需 key |

---

## 已知边界

- **AIHOT 没有周报 / 月报的公开 API**（已实测 `monthlies` 等 4 个端点均返回 404）。官网月报页的「本月主线」综述段落与「本期看点」主题聚类属于编辑成品，接口无法获取。本项目的周报 / 月报由**日报归档的官方每日导语聚合**而成，页面结构对齐官方版式，但内容非官方编辑成品。
- `items` 接口时间窗仅支持 `24h` 与 `7d`，无法统计月度精选总数，月报统计条以「期日报汇聚」替代。
- 单日报条目数波动较大（实测 2～21 条），弹窗已做空态处理。
- 天气数据源为 Open-Meteo 全球模型，国内精度约 1～2°C 偏差；如需本土高精度，可申请和风天气 key 后替换。

## 本地运行

```bash
cd ai-daily-dashboard
python3 -m http.server 3001
# 打开 http://127.0.0.1:3001/
```

也可直接用编辑器打开 `index.html`（建议通过本地服务访问，部分浏览器对 `file://` 的 fetch 有限制）。

## 部署

纯静态单文件，任何静态托管均可。当前使用 GitHub Pages：

1. Push 到 `main` 分支
2. 仓库 **Settings → Pages → Deploy from a branch** → `main` → `/(root)`
3. 1～2 分钟后生效

## 技术说明

- **单文件架构**：全部 CSS / JS 内联于 `index.html`，无构建步骤、无第三方库
- **客户端渲染**：页面加载时并行请求多个 API，`fetchViewData()` 按视图分流；搜索、筛选、主题切换、视图切换均为本地重渲染，不重复请求
- **视图数据缓存**：`viewData` 缓存已加载视图，切换 tab 零延迟
- **持久化**：`localStorage` 记忆主题、收藏、已读、当前视图、城市
- **时间处理**：所有 ISO 时间转北京时间（UTC+8），格式为「2026年9月9日 08:14」，不展示原始 ISO 字符串
